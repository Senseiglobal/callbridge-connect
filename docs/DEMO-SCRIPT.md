# Three-minute video plan

Use English. Record genuine behavior. Do not imply the fictional preview is a phone conversation. Keep keys, access codes and full phone numbers off screen. Obtain the speaker's permission to record and publish their voice.

| Time | Show | Suggested narration |
| --- | --- | --- |
| 0:00–0:20 | Dashboard and project name | “This is CallBridge Connect. Independent creators can have a project plan but still get stuck. CallBridge uses CALL-E to turn an opted-in check-in into a practical next-action brief.” |
| 0:20–0:45 | Create a request, minimal context, consent checkbox | “Aura Manager is the first integration example: an AI creative-project workspace. This check-in only needs the project stage, deadline and support question. Creating it does not call anyone.” |
| 0:45–1:00 | Sample preview and no-call banner | “Preview is a labelled example, with no phone activity. Live calling is a separate, confirmed action.” |
| 1:00–1:45 | Real call to the consenting owner's phone | Show confirmation, then a short actual exchange: AI disclosure, storyboard blocker, two-week deadline, next action, requested human follow-up and a callback window. Label any cuts honestly. |
| 1:45–2:20 | Refresh and show the actual result | “Here is the real CALL-E run ID and structured result: blocker, urgency, deadline risk, next action and whether human help was requested.” |
| 2:20–2:45 | Operator review / integration screen | “The human reviews the brief and owns any follow-up. CallBridge does not impersonate a human or change the creator's account.” |
| 2:45–3:00 | Repository and public demo | “The reusable app includes the CALL-E SDK integration, a safe demo, setup instructions and automated no-call tests.” |

If the live call does not work, stop and diagnose it. Do not substitute sample output and narrate it as real. Record again once the call and result are verified.

Upload to YouTube or Vimeo, set visibility to **Public**, and test the link in a signed-out/private window.
